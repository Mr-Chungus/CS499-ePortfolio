# CS 499 ePortfolio

This repository contains my Computer Science capstone ePortfolio for Southern New Hampshire University.

## Portfolio Focus

The portfolio demonstrates skills in:

- Software Design and Engineering
- Algorithms and Data Structures
- Databases
- Security
- Professional communication

## Main Artifact

The primary artifact is an Animal Shelter Dashboard originally created in CS-340 Client/Server Development. The application uses Python and MongoDB and was enhanced in three areas:

1. **Software Design and Engineering** — modular application structure, configuration management, logging, validation, and maintainability.
2. **Algorithms and Data Structures** — weighted rescue suitability ranking using dictionaries, sets, lists, scoring, and sorting.
3. **Databases** — safer CRUD operations, validation, indexes, auditing, and improved error handling.

## Site

The repository is structured as a GitHub Pages ePortfolio. The main page is `index.html` and the styling is contained in `style.css`.

Additional narrative pages, the final enhanced artifact, and the code review video link will be added as the capstone is finalized.
